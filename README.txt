ОБНОВЛЕНИЕ: ВЫБОР СОТРУДНИКА В ОТЧЁТАХ И ОХВАТАХ

1. Откройте репозиторий AlexanderVukolov/bloggers на GitHub.
2. Нажмите Add file → Upload files.
3. Перетащите все 7 файлов из этой папки в корень репозитория.
4. Подтвердите замену файлов и нажмите Commit changes.
5. Подождите 1–3 минуты и откройте сайт с полным обновлением страницы.

Что изменено:
- в «Отчёты и фактические охваты» можно выбрать любого активного сотрудника;
- отчёты можно фильтровать по сотруднику;
- в ежедневной сводке доступны сотрудники из вкладки «Сотрудники»;
- для менеджеров показываются KPI менеджера, для ассистентов — показатели ассистента;
- выбранный сотрудник сохраняется в отчёте, реальный автор остаётся в журнале действий;
- исправлена браузерная блокировка сохранения отчётов и охватов.
- перенесены последние записи старой версии: 309 карточек, дневные отчёты,
  планы, настройки менеджеров и 3 фактических охвата;
- восстановлены оклады, исторические имена и закрепления сотрудников;
- добавлен полный автоматический тест: блогер → карточка → размещение →
  выход → охваты → отчёт → KPI → зарплата;
- проверены мобильные точки перестроения, нижняя навигация и прокрутка таблиц.

Если после публикации видна старая версия: нажмите Ctrl+Shift+R (Windows) или Cmd+Shift+R (Mac).
