ОБНОВЛЕНИЕ NSL BLOGGERS — АДМИНИСТРАТОРЫ, СОТРУДНИКИ И KPI

1. Распакуйте архив.
2. На GitHub откройте AlexanderVukolov/bloggers → Add file → Upload files.
3. Загрузите семь файлов .js/.css из этой папки в корень репозитория с заменой.
4. Нажмите Commit changes и дождитесь публикации GitHub Pages.

Что изменено:
- Мария Штыкина получила роль администратора в общей базе и Supabase Auth.
- После добавления нового сотрудника автоматически создаётся персональная ссылка регистрации.
- Списки сотрудников во вкладках формируются из актуальной вкладки «Сотрудники».
- Администратор может вручную задать сумму KPI за охват за выбранный месяц.
- Ручная сумма сохраняется в базе и участвует в итоговом расчёте зарплаты.

Не загружайте ZIP-файл на GitHub: сначала распакуйте его и загрузите файлы отдельно.
