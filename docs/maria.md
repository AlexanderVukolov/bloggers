# Марии: проект инструкции (функции ещё не включены)

Откройте «Диагностика и исправления». «Проверить данные» показывает проблемы и связанные ID. Совпадение ника — повод проверить карточки, а не доказательство дубля.

Для импорта нажмите «Проверить таблицу». Проверьте созданные, обновляемые, пропускаемые строки и ошибки с листом/номером. Исправьте ID и неоднозначные связи. При ошибках применение блокируется. После повторной проверки подтвердите загрузку. При сбое возврата ID не создавайте строки заново: повторяется возврат ID сохранённой операции.

Для исправления выберите запись, причину и действие. Проверьте старые/новые значения, затем подтвердите. Для объединения нужно выбрать значения конфликтующих полей. Исключённые записи сохраняются; восстановление — archive с excluded=false. Если другой сотрудник уже изменил запись, проверьте актуальные значения заново.

Текущий интерфейс технический: параметры вводятся JSON. Для ежедневной работы он пока не готов. Не используйте его с рабочими данными до завершения проверки.
