# NSL Bloggers

Защищённая оболочка рабочего кабинета отдела блогеров.

- Публичная сборка содержит только интерфейс и не содержит карточек, отчётов, финансовых показателей или файлов сотрудников.
- Все рабочие данные загружаются после входа через проверяемую серверную сессию.
- Локальный кэш и сессия хранятся только до закрытия вкладки.
- Фото и договоры находятся в приватном хранилище и выдаются только авторизованным сотрудникам.

Публикация: GitHub Pages. Рабочая база и авторизация: Supabase.
