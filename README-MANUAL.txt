РУЧНАЯ ПУБЛИКАЦИЯ CRM «ОТДЕЛ БЛОГЕРОВ»

1. Откройте: https://github.com/AlexanderVukolov/bloggers
2. Если репозиторий пустой, нажмите «uploading an existing file».
   Если в нём уже есть файлы: Add file → Upload files.
3. Распакуйте архив и перетащите ВСЕ файлы из него в окно GitHub.
   Важно: файлы должны находиться в корне репозитория, а не внутри отдельной папки.
4. Нажмите Commit changes.
5. Откройте Settings → Pages.
6. В разделе Build and deployment выберите:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
7. Нажмите Save и подождите 2–5 минут.

Готовый адрес:
https://alexandervukolov.github.io/bloggers/

Для обновления программы в будущем загружайте новые версии файлов в тот же репозиторий.
